# EmuCore — Game Boy Color Emulator

Веб-эмулятор **Game Boy Color** (DMG/CGB), написанный на **TypeScript** с нуля, без зависимостей от готовых эмуляционных ядер. Работает прямо в браузере на базе **Vite** + **React** и рендерит изображение в `<canvas>` 160×144 с чёткими пикселями.

> 🚀 **Планы развития:** текущая кодовая база спроектирована так, чтобы в будущем стать полноценным эмулятором **Game Boy Advance** — архитектура модулей (CPU, PPU, APU, таймеры, прерывания, картриджи) готова к расширению.

## Возможности

- 🖥️ **Полный цикл эмуляции**: CPU (SM83), таймеры, прерывания, геймпад
- 🎨 **PPU** — графический процессор с поддержкой режимов Game Boy и Color
- 🔊 **APU** — звук через `AudioWorklet` (4 канала, стерео, 44100 Гц)
- 💾 **Картриджи**: загрузка ROM (.gb/.gbc), поддержка MBC
- ⏪ **Сохранения**: сейв-стейты в памяти, экспорт/импорт в файл (`.gbstate`, CRC-контроль)
- ⏩ **Двойная скорость** (CGB double speed), HBlank DMA
- 🎮 **Управление с клавиатуры**

## Управление

| Клавиша | Действие |
|---------|----------|
| Стрелки | D-Pad |
| `Z` | Кнопка A |
| `X` | Кнопка B |
| `Enter` | Start |
| `Backspace` | Select |
| `F5` / `F6` | Сейв-стейт / загрузка сейв-стейта |

## Запуск

```bash
npm install
npm run dev
```

## Тесты

```bash
npm test
```

Набор юнит-тестов покрывает CPU, APU, геймпад, сейв-стейты, скорость CGB и захват кадров (см. [`tests/`](tests/)).

## Структура

- [`src/emulator/`](src/emulator/) — ядро эмулятора (CPU, PPU, APU, память, картридж, таймер, прерывания, геймпад)
- [`src/main.ts`](src/main.ts) — точка входа приложения
- [`public/gb-audio-worklet.js`](public/gb-audio-worklet.js) — аудио-ворклет для вывода звука
